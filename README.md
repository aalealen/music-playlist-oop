# music-playlist-oop

Учебный проект по объектно-ориентированному программированию на Python.
Реализованы классы `Track`, `Playlist` и `Player`, которые моделируют музыкальный плейлист и плеер.

## Что умеет проект

- Создавать треки с названием, исполнителем и длительностью.
- Добавлять треки в плейлист.
- Показывать все треки плейлиста с нумерацией.
- Считать общую длительность плейлиста в удобном формате (минуты и секунды).
- Искать треки по исполнителю.
- Управлять воспроизведением: выбирать плейлист, переключать треки вперёд и назад (по кругу).
